# 沉沦者的黑流树海 · 藏品工具

《明日方舟》集成战略第六主题「沉沦者的黑流树海」的收藏品数据工具，数据来源：[路标档案馆 · 藏品池](https://www.lubiao.wiki/pools/rogue_6)。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `藏品获取筛选器_诡意行商_湖中仙女_险路恶敌.html` | 按获取来源交叉筛选（诡意行商 / 湖中仙女 / 险路恶敌），支持名称搜索 |
| `沉沦者的黑流树海_收藏品一览表.html` | 285 件藏品完整一览表（稀有度 / 售价 / 失与得 / 藏品池 / 获取节点），支持搜索与筛选 |
| `沉沦者的黑流树海_收藏品一览表.xlsx` | 上述一览表的 Excel 版本 |
| `collectibles_data.csv` | 提取后的结构化数据（285 行 × 8 列） |

## 数据字段约定

- 稀有度（从低到高）：`N`（普通）、`R`（稀有）、`SR`（超稀有）
- 诡意行商售价：按稀有度 `N=8 / R=12 / SR=16` 源石锭（PRTS「行商售价」基准），「不可购买」表示不在诡意行商常规库存
- 失与得：可交换 / 不可交换

## 生成脚本

`extract.py` / `build.py` / `build_filter.py` 从归档 JSON（`/data/archives/blackstream.json`）重新生成上述文件。
